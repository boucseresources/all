**8086-এর ভেতরে দুইটি প্রধান unit আছে:**

| Unit | Full form | প্রধান কাজ |
|---|---|---|
| **EU** | Execution Unit | Instruction decode ও execute করা |
| **BIU** | Bus Interface Unit | Instruction আনা এবং memory/I/O-এর সঙ্গে data transfer করা |

সহজ করে: **BIU এনে দেয়, EU বুঝে কাজ করে।**

**EU কী করে?**

EU instruction **decode** করে—কোন কাজ করতে হবে বোঝে—তারপর **execute** করে।

এর মধ্যে থাকে:

- **ALU:** যোগ, বিয়োগ এবং AND, OR-এর মতো operation করে।
- **Registers:** CPU-এর ভেতরে অল্প তথ্য সাময়িকভাবে রাখে।
- **Flag register:** ফলাফলের অবস্থা ও কিছু control information রাখে।
- **Instruction decoder:** instruction-এর অর্থ নির্ধারণ করে।

Registers ও flags আমরা আলাদা করে শিখব।

**BIU কী করে?**

BIU বাইরের **memory ও I/O devices-এর সঙ্গে bus-এর মাধ্যমে যোগাযোগ করে**। এটি instruction fetch করে, address পাঠায় এবং data read/write করে। EU-এর memory data প্রয়োজন হলে BIU সেই transfer সম্পন্ন করে।

BIU আগে থেকে আনা instruction bytes একটি **6-byte instruction queue**-তে রাখে।

**Queue কেন দরকার?**

ধরো, EU এখন একটি যোগের instruction execute করছে। তখন external bus ফাঁকা থাকলে এবং queue-তে জায়গা থাকলে BIU পরের instruction bytes এনে রাখতে পারে।

EU বর্তমান কাজ শেষ করে queue থেকে পরের instruction নেয়। ফলে instruction আনার জন্য অপেক্ষা কমে।

এই **instruction fetching ও execution-এর overlap**-কে এখানে **pipelining** বলা হচ্ছে।

খেয়াল রাখো:

- **6 bytes মানে 6টি instruction নয়।** একেক instruction-এর দৈর্ঘ্য আলাদা হতে পারে।
- Queue চলে **FIFO — First In, First Out** নিয়মে: আগে আসা byte আগে বের হয়।
- EU ও BIU একই সময়ে কাজ করতে পারে; তবে EU-এর memory/I/O transfer-এর জন্যও BIU প্রয়োজন।

**Exam answer: Explain the roles of the EU and BIU.**

“The 8086 consists of two major units: the Execution Unit (EU) and the Bus Interface Unit (BIU). The EU decodes and executes instructions. The BIU handles instruction fetching and all memory and I/O bus operations. It stores prefetched instruction bytes in a 6-byte FIFO queue. Overlapping instruction fetching with execution improves processing speed.”

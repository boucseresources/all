# Some Tips and Tricks

??? "Convert Hex to Decimal"

    ⚡ The 2-Step Mental Shortcut

    For any 2-digit hex number, you can always solve it instantly in your head using this breakdown:
    1. Multiply the first digit by 16: 2 × 16 = 32
    2. Add the second digit: 32 + 11 = 43

    Why this beats going through binary:

    If you converted to binary first (using the 8421 method), you would get 0010 1011. To find the decimal value from there, you would have to add up the binary weights: \(32 + 8 + 2 + 1 = 43\).
    Multiplying the first digit by 16 skips that extra math completely.

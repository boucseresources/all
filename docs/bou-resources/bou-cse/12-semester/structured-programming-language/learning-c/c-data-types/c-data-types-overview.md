# 🧠 "Data Types" মানে কী?

👉 আপনি যখন কোনো ভ্যারিয়েবল বানান C তে, তখন C কে জানাতে হয় এই ভ্যারিয়েবলে **কী ধরনের তথ্য** রাখা হবে।

🧊 যেমন ফ্রিজে রাখেন ঠান্ডা জিনিস
👕 আলমারিতে রাখেন জামাকাপড়
ঠিক তেমনই 👉

* `int` = শুধু সংখ্যা (ভগ্নাংশ ছাড়া)
* `float` = দশমিকসহ সংখ্যা
* `char` = ১টা অক্ষর (A, B, C)

---

# 📦 Data Type ক্যান লাগে?

✅ কারণ C একটা **strongly typed language**, অর্থাৎ C আগে থেকেই জানে সে কী টাইপের ডেটা রাখবে।
⚠️ যদি আপনি ভুল টাইপ ব্যবহার করেন, তাহলে প্রোগ্রাম **ক্র্যাশ করতে পারে** ❌।

---

# 📊 Basic Data Types (টেবিল সহ)

| 🔤 ডেটা টাইপ | 📏 সাইজ (মেমোরি) | 🎯 কী রাখে                      | 🔢 উদাহরণ                  | 🖨️ প্রিন্ট করার format |
| ------------ | ---------------- | ------------------------------- | -------------------------- | ----------------------- |
| `int`        | ২ বা ৪ বাইট      | পূর্ণ সংখ্যা (1, 2, 99)         | `int x = 5;`               | `%d` বা `%i`            |
| `float`      | ৪ বাইট           | দশমিক সংখ্যা (1.23)             | `float y = 3.14;`          | `%f`                    |
| `double`     | ৮ বাইট           | বড় দশমিক সংখ্যা (15 ঘর পর্যন্ত) | `double z = 3.1415926535;` | `%lf`                   |
| `char`       | ১ বাইট           | ১টি ক্যারেক্টার/ASCII           | `char c = 'A';`            | `%c`                    |

---

# ✅ সঠিক উদাহরণ

```c
#include <stdio.h>

int main() {
    int myNum = 5;             // 🔢 সংখ্যা
    float myFloatNum = 5.99;   // 🌊 দশমিক সংখ্যা
    char myLetter = 'D';       // 🔤 ১টা ক্যারেক্টার

    // 🖨️ প্রিন্ট করি
    printf("%d\n", myNum);        // Output: 5
    printf("%f\n", myFloatNum);   // Output: 5.990000
    printf("%c\n", myLetter);     // Output: D

    return 0;
}
```

📌 **ব্যাখ্যা:**

* `%d` = int টাইপের জন্য
* `%f` = float টাইপের জন্য
* `%c` = char টাইপের জন্য

---

# ⚠️ যদি ভুল ফরম্যাট দেন?

| ❌ ভুল কোড             | 🔍 সমস্যা                                                    | ✅ সঠিক কোড            |
| --------------------- | ------------------------------------------------------------ | --------------------- |
| `printf("%d", 3.14);` | `%d` শুধু int এর জন্য, float এর জন্য নয়                      | `printf("%f", 3.14);` |
| `char letter = "A";`  | double quote দিয়ে স্ট্রিং হয়, এক অক্ষর হলে single quote লাগে | `char letter = 'A';`  |
| `printf("%c", 65);`   | যদিও 65 একটা সংখ্যা, ASCII হিসেবে এটা 'A'                    | এটা technically ঠিক ✅ |

# 📚 Format Specifier Quick Table

| 📌 Format    | 👇 ইউজ হয়            | 🛠️ কাজ                        |
| ------------ | -------------------- | ------------------------------ |
| `%d` বা `%i` | `int`                | সংখ্যা প্রিন্ট                 |
| `%f`         | `float`              | দশমিক সহ সংখ্যা                |
| `%lf`        | `double`             | বড় দশমিক সংখ্যা                |
| `%c`         | `char`               | ১টি অক্ষর প্রিন্ট              |
| `%s`         | স্ট্রিং (char array) | বাক্য বা শব্দ (string) প্রিন্ট |

# 💡 BONUS: ASCII টেবিল বুঝুন

```c
char ch = 65;
printf("%c", ch);  // Output: A
```

👉 এখানে `65` মানে ASCII অনুযায়ী 'A'
এইভাবে `char` আর `int` মাঝে মাঝে **পরস্পর পরিবর্তনযোগ্য**।

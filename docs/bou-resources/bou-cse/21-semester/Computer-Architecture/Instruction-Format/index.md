# L-1.13: What is Instruction Format | Understand Computer Organisation with Simple Story

এখানে গেট স্ম্যাশার্স (Gate Smashers)-এর **"What is Instruction Format"** ভিডিওটির সম্পূর্ণ এবং বিস্তারিত লেকচার নোট দেওয়া হলো। কোনো অংশ বাদ না দিয়ে প্রতিটি পয়েন্ট বাংলায় সহজভাবে আলোচনা করা হয়েছে:


### ১. প্রাথমিক ধারণা ও সাধারণ গল্প (The Basic Concept & Story)

ভিডিওর শুরুতে সি ল্যাঙ্গুয়েজের (C Language) একটি সাধারণ প্রোগ্রামের উদাহরণ দিয়ে পুরো কম্পিউটার অর্গানাইজেশনের কার্যপদ্ধতি বোঝানো হয়েছে:

```c
main() {
    int a = 10;
    int b = 20;
    int c;
    c = a + b;
    printf(c);
}

```

* **ডেটা এবং ইনস্ট্রাকশন (Data vs. Instruction):** এখানে `10` এবং `20` হলো **ডেটা (Data)**। আর `c = a + b` হলো **ইনস্ট্রাকশন (Instruction)** বা নির্দেশ, যা কম্পিউটারকে বলছে ওই ডেটা নিয়ে কী কাজ করতে হবে।
* **কম্পাইলেশন (Compilation):** আমরা যখন এই হাই-লেভেল কোডটি রান বা কম্পাইল করি, তখন এটি মেশিন ল্যাঙ্গুয়েজে (Machine Language) রূপান্তরিত হয়। এই মেশিন ল্যাঙ্গুয়েজ মূলত অনেকগুলো **মাইক্রো-ইনস্ট্রাকশন (Micro-instructions)** বা নির্দেশাবলীর সেট।

### ২. মেমোরি এবং ভন নিউম্যান আর্কিটেকচার (Memory & Von Neumann Architecture)

* **ভন নিউম্যান আর্কিটেকচার (Von Neumann Architecture)** অনুযায়ী, কম্পিউটারের মেমোরি বা র‍্যামের (RAM) ভেতরেই ডেটা এবং ইনস্ট্রাকশন—উভয়ই একসাথে অবস্থান করে।
* ডেটা কখনো কখনো সরাসরি রেজিস্টারে থাকতে পারে, তবে সাধারণত তা প্রথমে মেমোরিতেই থাকে এবং সেখান থেকে প্রয়োজনে রেজিস্টারে কপি করা হয়।

### ৩. সিপিইউ-এর ভেতরের গঠন (Inside the CPU)

সিপিইউ সরাসরি মেমোরির সাথে কাজ করার আগে তার ভেতরের বিভিন্ন ইউনিটের সাহায্য নেয়:

* **ALU (Arithmetic Logic Unit):** এর মূল দায়িত্ব হলো যেকোনো গাণিতিক (যেমন: যোগ, বিয়োগ) এবং যৌক্তিক (Logical) কাজ সম্পন্ন করা।
* **CU (Control Unit):** এটি পুরো প্রসেসিংয়ের কাজ নিয়ন্ত্রণ বা ডিরেক্ট করে।
* **রেজিস্টারস (Registers):** সিপিইউ-এর কাজের সুবিধার জন্য তার সাথে সরাসরি কিছু উচ্চগতির মেমোরি বা রেজিস্টার যুক্ত থাকে। যেমন: এক্যুমুলেটর (Accumulator - AC), ডাটা রেজিস্টার (Data Register - DR), ইনপুট রেজিস্টার, আউটপুট রেজিস্টার এবং ইনস্ট্রাকশন রেজিস্টার (Instruction Register - IR)।


### ৪. ইনস্ট্রাকশন ফরম্যাট (Instruction Format)

মেমোরি থেকে যখন কোনো ইনস্ট্রাকশন প্রসেসরে আসে, তখন তার একটি নির্দিষ্ট ফরম্যাট বা গঠন থাকে। একটি আদর্শ ইনস্ট্রাকশন ফরম্যাটে মূলত ৩টি অংশ থাকে:

| অংশ (Field) | কাজ/অর্থ (Meaning) |
| | |
| **মোড (Mode / Addressing Mode)** | এটি নির্দেশ করে যে অপারেন্ড বা ডেটাটি মেমোরি বা রেজিস্টারের ঠিক **কোথায় এবং কীভাবে** আছে। |
| **অপকোড (Opcode / Operation Code)** | এটি কম্পিউটারের ব্রেনকে বলে দেয় ঠিক **কী কাজ** করতে হবে (যেমন: ADD, SUB, MUL, DIV, SHIFT)। |
| **অপারেন্ড (Operand)** | এটি মূলত ডেটা বা সেই ডেটার ঠিকানা (Address)। যার ওপর অপকোডটি কাজ করবে। |

#### অ্যাড্রেসিং মোড (Addressing Mode)-এর কয়েকটি সাধারণ ধরণ:

১. **ইমিডিয়েট (Immediate):** ইনস্ট্রাকশনের ভেতরেই সরাসরি ডেটা (কনস্ট্যান্ট) দেওয়া থাকে।
২. **ডাইরেক্ট মেমোরি (Direct Memory):** সরাসরি মেমোরির একটি অ্যাড্রেস দেওয়া থাকে, যেখানে গিয়ে ডেটা আনতে হয়।
৩. **রেজিস্টার (Register):** কোনো রেজিস্টারের অ্যাড্রেস দেওয়া থাকে এবং ডেটা সেই রেজিস্টারের ভেতরে থাকে।
৪. **ইনডাইরেক্ট (Indirect):** ইনস্ট্রাকশনে একটি অ্যাড্রেস দেওয়া থাকে, সেখানে গেলে আরেকটি অ্যাড্রেস পাওয়া যায় এবং সেই দ্বিতীয় অ্যাড্রেসে আসল ডেটা থাকে।


### ৫. একটি ইনস্ট্রাকশন কীভাবে কাজ করে? (Step-by-Step Instruction Cycle)

মেমোরি থেকে একটি নির্দেশ এসে কীভাবে মনিটরে ফলাফল দেখায়, তার পুরো চক্রটি নিচে দেওয়া হলো:

১. **ইনস্ট্রাকশন ফেচ (Instruction Fetch):** প্রথমে মেইন মেমোরি থেকে ইনস্ট্রাকশনটিকে টেনে এনে সিপিইউ-এর **ইনস্ট্রাকশন রেজিস্টার (Instruction Register - IR)**-এ রাখা হয়।
২. **ডিকোডিং (Decoding):** এরপর কন্ট্রোল ইউনিট সেই ইনস্ট্রাকশনটিকে ভেঙে বা ডিকোড করে বোঝে যে অপকোডটি আসলে কী এবং অপারেন্ড বা ডেটা কোথায় আছে।
৩. **অপারেন্ড ফেচ (Operand Fetch):** ডেটার অবস্থান জানার পর মেমোরি বা রেজিস্টার থেকে ডেটা এনে **এক্যুমুলেটর (AC)** বা **ডাটা রেজিস্টার (DR)**-এ রাখা হয়।
৪. **এক্সিকিউশন (Execution):** এবার **ALU** তার কাজ শুরু করে এবং ডেটাগুলোর ওপর নির্দিষ্ট অপারেশন (যেমন: ১০ + ২০ যোগ করা) সম্পন্ন করে।
৫. **ফলাফল সংরক্ষণ (Output Store):** যোগফলটি (৩০) **আউটপুট রেজিস্টার (Output Register)**-এ পাঠানো হয়, যা মনিটরে বা স্ক্রিনে আউটপুট হিসেবে ভেসে ওঠে।


### ৬. ইনস্ট্রাকশনের দৈর্ঘ্য এবং কম্পিউটারের প্রকারভেদ (Instruction Length & System Types)

* একটি ইনস্ট্রাকশনের সাইজ বা দৈর্ঘ্য কতটা বড় হবে, তা নির্ভর করে কম্পিউটার আর্কিটেকচার বা অর্গানাইজেশনের ওপর:
* **সিঙ্গেল এক্যুমুলেটর সিস্টেম (Single Accumulator System):** এখানে সাধারণত ১-অ্যাড্রেস ইনস্ট্রাকশন (1-Address Instruction) ব্যবহার করা হয়।
* **জেনারেল রেজিস্টার অর্গানাইজেশন (General Register Organization):** এখানে ২-অ্যাড্রেস (2-Address) বা ৩-অ্যাড্রেস ইনস্ট্রাকশন (3-Address Instruction) ব্যবহার করা সম্ভব।


* **হার্ডওয়্যারের ওপর প্রভাব:** ইনস্ট্রাকশনে অ্যাড্রেসের সংখ্যা যত বেশি হবে, ইনস্ট্রাকশনের দৈর্ঘ্য (Length) তত বাড়বে। আর ইনস্ট্রাকশন বড় হলে তা বহন করার জন্য **ইনস্ট্রাকশন রেজিস্টার (IR)** এবং ভেতরের **কমন ডাটা বাস (Common Data Bus)**-এর সাইজও বড় করতে হয়।

### ৭. সারসংক্ষেপ (Summary)

ভিডিওর শেষে বলা হয়েছে, পাইপলাইনিং (Pipelining) বা ইনস্ট্রাকশন সাইকেলের মতো কঠিন টপিকগুলো ভালোভাবে বুঝতে হলে এই বেসিক ইনস্ট্রাকশন ফরম্যাটের ধারণা থাকা অত্যন্ত জরুরি। পরবর্তী লেকচারে ০-অ্যাড্রেস, ১-অ্যাড্রেস, ২-অ্যাড্রেস এবং ৩-অ্যাড্রেস ইনস্ট্রাকশন নিয়ে বিস্তারিত আলোচনা করা হবে।

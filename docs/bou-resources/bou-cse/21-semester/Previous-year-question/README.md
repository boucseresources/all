# BOU CSE Second Year First Semester Question Bank

This collection transcribes the supplied term examination papers into editable Markdown. It contains eight subject-level master files and 55 separate chapter files.

## Organization

`Subject -> Handbook chapter -> Term -> Original question number and subpart`

The wording, numbering, marks, mathematical expressions, and code fragments follow the supplied question papers. Printed figures, graphs, tables, chemical structures, and GUI/class diagrams are stored in `assets` and embedded at the relevant question.

- Edit a complete subject in the Markdown file at the root of this folder.
- Edit one chapter at a time in `chapters/<course-code>/`.
- Keep the relative folder structure unchanged so embedded images continue to display.
- Mathematical notation uses standard Markdown-compatible LaTeX between `$...$` and `$$...$$`.

# Run Java without any IDE

কমান্ড লাইনের (Command Line) মাধ্যমে কীভাবে একটি জাভা প্রোগ্রাম কম্পাইল এবং রান করতে হয়, সেই সম্পর্কিত ভিডিওর বিস্তারিত নোট নিচে বাংলায় দেওয়া হলো:

### জাভা প্রোগ্রাম কমান্ড লাইনে রান করার সম্পূর্ণ গাইড

আইডিই (যেমন- NetBeans বা Eclipse) ব্যবহার না করে কীভাবে একদম শুরু থেকে কমান্ড প্রম্পটের সাহায্যে জাভা প্রোগ্রাম রান করা যায়, তার ধারাবাহিক ধাপগুলো নিচে আলোচনা করা হলো:

#### ১. প্রাথমিক জাভা কোড তৈরি

* প্রথমে একটি টেক্সট এডিটর (যেমন- Notepad বা Notepad++) ওপেন করতে হবে। প্রাথমিক অবস্থায় কোডিং শেখার জন্য আইডিই-এর চেয়ে সাধারণ টেক্সট এডিটরে কোড লেখা বেশি উপকারী, কারণ এতে জাভার বিভিন্ন মেথড বা সিনট্যাক্স স্বয়ংক্রিয়ভাবে আসে না এবং নিজের টাইপ করার মাধ্যমে প্র্যাকটিস ভালো হয়।
* একটি সাধারণ ক্লাস তৈরি করতে হবে, যেমন:
```java
class Test {
    public static void main(String[] args) {
        System.out.println("Hello I am Anisul Islam");
    }
}

```


* এরপর ফাইলটি ক্লাসের নাম অনুযায়ী **Test.java** নামে সেভ করতে হবে। ভিডিওতে ফাইলটি কম্পিউটারের **Desktop**-এ সেভ করা হয়েছে।

#### ২. জাভা কম্পাইলার এনভায়রনমেন্ট পাথ সেটআপ (Path Setup)

যদি কমান্ড লাইনে সরাসরি জাভা কোড কম্পাইল করতে গিয়ে এরর (যেমন: `javac is not recognized...`) দেখায়, তবে নিচের নিয়ম অনুযায়ী পাথ সেট করতে হবে:

* প্রথমে জাভা ইনস্টল করা ফোল্ডারে যেতে হবে: `C:\Program Files\Java\jdk...\bin`
* **bin** ফোল্ডারে থাকা **javac** (জাভা কম্পাইলার) ফাইলের পাথ বা লোকেশনটি কপি করতে হবে।
* এরপর কম্পিউটারের **Properties**-এ গিয়ে **Advanced system settings**-এ ক্লিক করতে হবে।
* সেখান থেকে **Environment Variables**-এ যেতে হবে।
* **User variables** অংশে **New** বাটনে ক্লিক করে ভ্যারিয়েবলের নাম দিতে হবে `path`।
* ভ্যারিয়েবল ভ্যালুর ঘরে দুটি পার্সেন্টেজ চিহ্নের মাঝে পাথ লিখতে হবে, যেমন: `%path%;;[কপি করা পাথটি এখানে পেস্ট করতে হবে]` এবং **OK** দিয়ে সেটিংস সেভ করতে হবে।
* পাথ ঠিকমতো সেট হয়েছে কিনা তা চেক করতে কমান্ড প্রম্পটে `javac` লিখে এন্টার দিলে অনেকগুলো কমান্ডের তালিকা চলে আসবে।

#### ৩. কমান্ড লাইনের স্ক্রিন ক্লিয়ার করা

* কমান্ড প্রম্পটের স্ক্রিনে অতিরিক্ত লেখাগুলো মুছে ফেলার জন্য `cls` লিখে এন্টার দিলে স্ক্রিনটি একদম পরিষ্কার বা ক্লিয়ার হয়ে যাবে।

#### ৪. ডিরেক্টরি পরিবর্তন ও ফাইল কম্পাইল করা

* যেহেতু জাভা ফাইলটি ডেক্সটপে সেভ করা হয়েছে, তাই কমান্ড প্রম্পটে ডিরেক্টরি পরিবর্তন করতে `cd Desktop` লিখে এন্টার চাপতে হবে।
* এরপর ফাইলটি কম্পাইল করার জন্য লিখতে হবে: `javac Test.java`
* কোডে কোনো ভুল না থাকলে ফাইলটি সফলভাবে কম্পাইল হবে এবং ডেক্সটপে **Test.class** নামে একটি নতুন ক্লাস ফাইল তৈরি হবে।

#### ৫. জাভা প্রোগ্রাম রান করা

* কম্পাইল সম্পন্ন হওয়ার পর প্রোগ্রামটি রান করতে লিখতে হবে: `java Test` (এখানে ডট জাভা এক্সটেনশন লেখার প্রয়োজন নেই)।
* এন্টার চাপলেই স্ক্রিনে কাঙ্ক্ষিত আউটপুটটি দেখা যাবে।

#### ৬. কোড এডিট এবং পুনরায় রান করা

* যদি কোডে নতুন কোনো লাইন যুক্ত করা হয় (যেমন: `System.out.println("This is second line");`), তবে ফাইলটি আবার সেভ করতে হবে।
* আগের ব্যবহার করা কমান্ডগুলো বারবার টাইপ না করে কিবোর্ডের **Up Arrow** এবং **Down Arrow** কি (Key) ব্যবহার করে আগের কমান্ডগুলো স্ক্রিনে ফিরিয়ে আনা যায়।
* এডিট করার পর আবার প্রথমে `javac Test.java` দিয়ে কম্পাইল এবং পরবর্তীতে `java Test` লিখে রান করলে নতুন আউটপুটটি স্ক্রিনে প্রদর্শিত হবে।

# কিছু প্রশ্ন ও উত্তরঃ

## Site ব্যবহারের নিয়মাবলীঃ

<!-- prettier-ignore-start -->
!!! folder "কীভাবে এই সাইট ব্যবহার করতে পারি?"
    
    নিচের নির্দেশনা মেনে সাইটটি ব্যবহার করলে আপনি দ্রুত ও সহজে কন্টেন্ট খুঁজে পাবেন এবং নেভিগেশন আরও স্বাচ্ছন্দ্যময় হবে।

    **🔍 Search ব্যবহার**
    - উপরের ডানদিকে থাকা সার্চ বক্সে যেকোনো শব্দ লিখলেই তাৎক্ষণিক ফলাফল পাবেন।
    - সার্চ রেজাল্টে ++up++ / ++down++ দিয়ে নেভিগেট করুন এবং ++enter++ চাপুন পেজ খোলার জন্য।
    - সার্চ বারে `#` লিখে সেকশন অনুযায়ী খুঁজতে পারেন।

    **📂 Sidebar Navigation**
    - বাম পাশের Sidebar দিয়ে অধ্যায়, সেকশন বা ফোল্ডার ধরে কন্টেন্ট ব্রাউজ করুন।
    - ফোল্ডার আইকনে ক্লিক করলে সেটি প্রসারিত বা সংকুচিত হবে।
    - বর্তমানে যে পেজে আছেন তা **হাইলাইট** হয়ে থাকবে।

    **⌨️ Keyboard Shortcuts**
    - ++slash++ বা ++s++ → সার্চ বক্সে সরাসরি যেতে।
    - ++n++ → পরবর্তী পেজে যাওয়া।
    - ++p++ → পূর্ববর্তী পেজে যাওয়া।
    - ++up++ / ++down++ → সার্চ রেজাল্ট বা মেনুতে উপরে-নিচে যাওয়া।

    **⚡ Key bindings (Plugin দ্বারা যুক্ত)**
    
    | Key    | Action                                   |
    |--------|------------------------------------------|
    | ++b++  | Toggle both (TOC এবং Navigation)          |
    | ++m++  | Toggle Navigation menu                   |
    | ++t++  | Toggle Table of Contents (TOC)           |

    **📱 মোবাইল ব্যবহারকারীদের জন্য**
    - বাম উপরের ☰ (menu) আইকনে ক্লিক করে Sidebar খুলুন।
    - সার্চ বক্স ব্যবহার করতে উপরের 🔍 আইকনে ক্লিক করুন।
    - কন্টেন্ট পড়ার সময় Sidebar স্বয়ংক্রিয়ভাবে লুকানো থাকবে, যাতে পড়া সহজ হয়।

    **💡 বাড়তি টিপস**
    - যদি কোনো লিংক বা টেক্সট কপি করতে চান, মাউস দিয়ে সিলেক্ট করুন → রাইট ক্লিক → Copy।
    - কোড ব্লকের ডানদিকে থাকা 📋 আইকনে ক্লিক করলে পুরো কোড কপি হয়ে যাবে।
    - পেজের নিচে **Back to top** বাটনে ক্লিক করে দ্রুত উপরে যেতে পারবেন।

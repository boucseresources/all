## Site ব্যবহারের নিয়মাবলীঃ


## 🔍 কন্টেন্ট খোঁজা (Search)

!!! tip "কীভাবে সার্চ করবেন?"
    - উপরের ডান কোণে থাকা সার্চ বক্সে যেকোনো শব্দ টাইপ করলেই মিল পাওয়া পেজগুলো দেখা যাবে।
    - সার্চ রেজাল্টে **++up++ / ++down++** দিয়ে নেভিগেট করুন, **++enter++** চাপলে পেজ খুলবে।
    - সার্চে `#` দিয়ে সেকশন-লেভেল রেজাল্টও পাওয়া যাবে।

## 📂 নেভিগেশন (Sidebar Navigation)

!!! note "Sidebar ব্যবহার"
    - বামপাশের **Sidebar**-এ অধ্যায়, সেকশন, বা টপিক অনুযায়ী ব্রাউজ করতে পারবেন।
    - ফোল্ডার আইকনে ক্লিক করলে সেটি খুলবে বা বন্ধ হবে।
    - বর্তমানে যেই পেজে আছেন, সেটি **হাইলাইট** হয়ে থাকবে।

---

## ⌨️ কিবোর্ড শর্টকাটস

!!! example "সাধারণ শর্টকাটস"
    - **++slash++** বা **++s++** → সরাসরি সার্চে যাওয়া
    - **++n++** → পরবর্তী পেজ
    - **++p++** → পূর্ববর্তী পেজ
    - **++up++ / ++down++** → সার্চ রেজাল্ট বা মেনুতে উপরে-নিচে যাওয়া

!!! example "প্লাগইন দ্বারা যুক্ত বাড়তি শর্টকাটস"
    | Key  | Action                                   |
    |------|------------------------------------------|
    | ++b++| Toggle Navigation + Table of Contents    |
    | ++m++| Toggle Navigation menu                   |
    | ++t++| Toggle Table of Contents (TOC)           |

## 📝 অ্যানোটেশন (Annotations) :material-comment-eye:

!!! tip "Annotation কীভাবে চিনবেন ও ব্যবহার করবেন?"
    - পেজে কখনও কখনও ছোট একটি **আইকন** :material-plus-circle: বা সংখ্যা চিহ্ন `(1)` দেখা যাবে।
    - এর মানে এখানে অতিরিক্ত ব্যাখ্যা বা গুরুত্বপূর্ণ নোট আছে :material-lightbulb-on:।
    - **ডেস্কটপ:** আইকনের উপর **মাউস রাখলে বা ক্লিক করলে** ব্যাখ্যা দেখা যাবে।
    - **মোবাইল:** আইকনে **ট্যাপ করলে** ব্যাখ্যা খুলবে।
    - বন্ধ করতে চাইলে আবার একই জায়গায় ক্লিক/ট্যাপ করুন।

## 📚 গ্লসারি ও সংক্ষিপ্ত রূপ (Glossary & Abbreviations) :material-book-search:

!!! info "Glossary কীভাবে ব্যবহার করবেন?"
    - কিছু শব্দ বা সংক্ষিপ্ত রূপ **আন্ডারলাইন** করা থাকবে :material-format-underline-wavy:।
    - এর মানে হলো এখানে সেই শব্দের বিস্তারিত অর্থ আছে :material-information-outline:।
    - **ডেস্কটপ:** আন্ডারলাইন করা টেক্সটে **মাউস রাখলে** অর্থ দেখা যাবে।
    - **মোবাইল:** আন্ডারলাইন করা টেক্সটে **ট্যাপ করলে** অর্থ দেখা যাবে।
    - অর্থ সবসময় **ইংরেজি + বাংলা** দুই ভাষাতেই দেখানো হবে।

## 🔗 সেকশন লিঙ্ক (Anchor Link) :material-link-variant:

!!! tip "Anchor Link কী এবং কিভাবে ব্যবহার করবেন?"
    - এই সাইটে প্রতিটি **হেডিং**-এর ডানপাশে একটি ছোট **লিঙ্ক আইকন** ¶ দেখা যায়।
    - ওই আইকনের উপর **মাউস রাখলে** "Anchor link to this section" বা অনুরূপ টুলটিপ দেখাবে।
    - আইকনে **ক্লিক করলে** আপনার ব্রাউজারের অ্যাড্রেসবারে ওই সেকশনের জন্য একটি সরাসরি লিঙ্ক তৈরি হবে।
    - এই লিঙ্কটি **কপি করে** আপনি অন্য কাউকে পাঠালে, সে সরাসরি সেই সেকশন খুলতে পারবে।
    - মোবাইলে এই ফিচার ব্যবহার করতে চাইলে **আইকনে ট্যাপ** করলেই লিঙ্ক কপি হবে (কিছু ব্রাউজারে কপি করতে আলাদা করে সিলেক্ট করতে হতে পারে)।

!!! example "উদাহরণ"
    - ধরুন আপনি **📂 নেভিগেশন (Sidebar Navigation)** সেকশনের লিঙ্ক শেয়ার করতে চান।
    - হেডিং-এর ডানপাশের :material-link: আইকনে ক্লিক করুন।
    - এখন ব্রাউজারের URL হবে এমন:
      ```
      https://example.com/#📂-নেভিগেশন-sidebar-navigation
      ```
    - এই লিঙ্কে ক্লিক করলে বা শেয়ার করলে সরাসরি ওই সেকশন খুলে যাবে।


## 📱 মোবাইল ব্যবহার

!!! info "মোবাইলে কিভাবে সাইট ব্যবহার করবেন?"
    - বাম উপরের ☰ (মেনু) আইকনে ক্লিক করে Sidebar খুলুন।
    - উপরের 🔍 আইকন দিয়ে সার্চ করুন।
    - পড়ার সময় Sidebar স্বয়ংক্রিয়ভাবে লুকানো থাকবে।

    নিজেকে একজন বাবুর্চি 🧑‍🍳 হিসেবে কল্পনা করুন, আর variableগুলো হলো আপনার রান্নার পাত্র (হাঁড়ি, কড়াই, বাটি)। ডেটা টাইপ হলো সেই পাত্রের গায়ে লাগানো লেবেল, যা আপনাকে বলে দেয় পাত্রটি কোন ধরণের উপাদান রাখার জন্য তৈরি। আপনি তো আর একটি ছড়ানো কড়াইতে স্যুপ রাখবেন না, তাই না? প্রোগ্রামিংয়ের ধারণাটাও ঠিক একই রকম!

    Data Type মানে:
    আপনার variable টা কেমন ধরনের ডাটা রাখতে পারবে, সেটা জানিয়ে দেয়া।
    🎯 যেমন — পূর্ণ সংখ্যা, দশমিক সংখ্যা, character ইত্যাদি।

    আপনি C-তে যখন কোন variable declare করো, তখন compiler কে জানাতে হয় —
    "ভাই, আমি এখানে কিসের ডাটা রাখতে চাই!"

    একটি ডেটা টাইপ কম্পিউটারকে দুটি খুব গুরুত্বপূর্ণ বিষয় বলে দেয়:
    ১. variableের জন্য কতটা মেমরি (জায়গা) সংরক্ষণ করতে হবে।
    ২. এটি কী ধরণের ডেটা সংরক্ষণ করবে (এবং এর ওপর কী কী অপারেশন, যেমন গণিত, করা যাবে)।

    চলুন, বেসিক ডেটা টাইপগুলো এক এক করে বিস্তারিতভাবে জেনে নিই।

    🧱 Syntax:¶

    <data_type> <variable_name> = <value>;

    ## পূর্ণসংখ্যা (Whole Numbers): int¶

    int ডেটা টাইপটি পূর্ণসংখ্যা সংরক্ষণের জন্য ব্যবহার করা হয়। এই সংখ্যাগুলো ধনাত্মক, ঋণাত্মক বা শূন্য হতে পারে, কিন্তু সেগুলোতে কোনো দশমিক বিন্দু থাকতে পারবে না।

    • এভাবে ভাবুন: এমন জিনিস গণনা করার জন্য যা ভাগ করা যায় না, যেমন একটি রুমে কতজন লোক আছে, একটি ঝুড়িতে কয়টি আপেল 🍎 আছে, বা আপনি কত ধাপ হেঁটেছেন।
    • মেমরি সাইজ: আধুনিক কম্পিউটারে সাধারণত 4 বাইট। বাইট হলো কম্পিউটার মেমরির একটি ক্ষুদ্র একক।
    • ফরম্যাট স্পেসিফায়ার: %d অথবা %i (দুটোই কাজ করে, তবে %d বা "decimal" বেশি প্রচলিত)।

    উদাহরণ¶

    ধরুন আপনি আপনার বয়স এবং বর্তমান সাল সংরক্ষণ করতে চান।

    #include <stdio.h>

int main() {
    // একটি 'int' variable ঘোষণা এবং শুরু করা হচ্ছে
    // প্রাথমিক মান (Initial Value): আমরা এর মান 25 নির্ধারণ করছি
    int amarBoyosh = 25;

    // আরেকটি 'int' variable
    // প্রাথমিক মান (Initial Value): আমরা এর মান 2025 নির্ধারণ করছি
    int bortomanSal = 2025;

    // আমরা ইন্টিজার দিয়ে গণিতও করতে পারি!
    int jonmoSal = bortomanSal - amarBoyosh;

    printf("হ্যালো! আমার বয়স %d বছর।\n", amarBoyosh);
    printf("বর্তমান সাল হলো %d।\n", bortomanSal);
    printf("তাহলে, আমার জন্ম সম্ভবত %d সালে।\n", jonmoSal);

    return 0;
}

    আউটপুট:

    হ্যালো! আমার বয়স 25 বছর।
বর্তমান সাল হলো 2025।
তাহলে, আমার জন্ম সম্ভবত 2000 সালে।

    ⚠️ সাধারণ ভুল: কী হবে যদি আপনি একটি int-এর মধ্যে দশমিক সংখ্যা রাখার চেষ্টা করেন?

    int vulShongkha = 9.99; // ❌ খারাপ আইডিয়া!

printf("%d\n", vulShongkha);

    আউটপুট:

    9

    কম্পিউটার সংখ্যাটিকে রাউন্ড করে না। এটি কেবল দশমিক অংশটি কেটে ফেলে (truncate করে)। এতে আপনার ডেটার একটি অংশ হারিয়ে যায়!

    দশমিক সংখ্যা (Numbers with Decimals): float and double¶

    যখন আপনার ভগ্নাংশ বা দশমিক বিন্দুসহ সংখ্যা সংরক্ষণ করার প্রয়োজন হয়, তখন আপনি ফ্লোটিং-পয়েন্ট টাইপ ব্যবহার করবেন। যেমন জিনিসের দাম 💰, কোনো কিছুর পরিমাপ, বা বৈজ্ঞানিক ডেটা। C আপনাকে দুটি প্রধান অপশন দেয়: float এবং double।

    মূল পার্থক্য হলো নির্ভুলতা (precision):

    • float: প্রায় ৬-৭ দশমিক স্থান পর্যন্ত নির্ভুল। এটি কম মেমরি (4 বাইট) ব্যবহার করে।
    • double: "ডাবল-প্রিসিশন"। প্রায় ১৫ দশমিক স্থান পর্যন্ত নির্ভুল। এটি বেশি নির্ভুল এবং বেশি মেমরি (8 বাইট) ব্যবহার করে।

    💡 সাধারণ নিয়ম: যদি আপনি নিশ্চিত না হন কোনটি ব্যবহার করবেন, তবে double ব্যবহার করাই নিরাপদ, কারণ এটি বেশি নির্ভুল।

    float এর উদাহরণ¶

    • ফরম্যাট স্পেসিফায়ার: %f
    #include <stdio.h>

int main() {
    // প্রাথমিক মান: দুটি দশমিক স্থানসহ একটি দাম
    float jinisherDam = 19.99;

    // প্রাথমিক মান: একটি গাণিতিক ধ্রুবক
    float pi_er_man = 3.14159;

    printf("জিনিসটির দাম হলো: ৳%f\n", jinisherDam);
    printf("Pi-এর একটি আনুমানিক মান হলো: %f\n", pi_er_man);

    // আপনি চাইলে দশমিকের পর কয়টি সংখ্যা দেখাবেন তা নিয়ন্ত্রণ করতে পারেন
    printf("শুধুমাত্র ২টি দশমিকসহ দাম হলো: ৳%.2f\n", jinisherDam);

    return 0;
}

    আউটপুট:

    জিনিসটির দাম হলো: ৳19.990000
Pi-এর একটি আনুমানিক মান হলো: 3.141590
শুধুমাত্র ২টি দশমিকসহ দাম হলো: ৳19.99

    double এর উদাহরণ¶

    • ফরম্যাট স্পেসিফায়ার: %lf ("long float"-এর জন্য)
    #include <stdio.h>

int main() {
    // প্রাথমিক মান: একটি অত্যন্ত নির্ভুল সংখ্যা
    double khubNirvulPI = 3.141592653589793;

    printf("PI-এর আরও নির্ভুল মান হলো: %lf\n", khubNirvulPI);

    // এর নির্ভুলতা দেখানোর জন্য ১৫টি দশমিক স্থানসহ প্রিন্ট করা হচ্ছে
    printf("ফরম্যাট করা PI: %.15lf\n", khubNirvulPI);

    return 0;
}

    আউটপুট:

    PI-এর আরও নির্ভুল মান হলো: 3.141592653589793
ফরম্যাট করা PI: 3.141592653589793

    ## একটি অক্ষর (Single Characters): char¶

    char ডেটা টাইপটি একটি মাত্র অক্ষর সংরক্ষণ করতে ব্যবহৃত হয়। এটি একটি বর্ণ, একটি সংখ্যা বা একটি প্রতীক হতে পারে।

    • এভাবে ভাবুন: আপনার কীবোর্ডের একটি বোতামের চাপ।
    • মেমরি সাইজ: সবসময় 1 বাইট।
    • কীভাবে লিখবেন: আপনাকে অবশ্যই একক উদ্ধৃতি চিহ্ন '' ব্যবহার করতে হবে। যেমন, 'A', 'k', '7', বা '$'।
    • ফরম্যাট স্পেসিফায়ার: %c

    উদাহরণ¶

    #include <stdio.h>

int main() {
    // প্রাথমিক মান: গ্রেডের জন্য 'A' অক্ষরটি
    char studentGrade = 'A';

    // প্রাথমিক মান: একটি একক সংখ্যার অক্ষর
    char buildingNumber = '4';

    // প্রাথমিক মান: একটি প্রতীক
    char mudraChinho = '৳';

    printf("ছাত্রের গ্রেড হলো: %c\n", studentGrade);
    printf("বিল্ডিং নম্বর হলো: %c\n", buildingNumber);
    printf("মুদ্রার প্রতীক হলো: %c\n", mudraChinho);

    return 0;
}

    আউটপুট:

    ছাত্রের গ্রেড হলো: A
বিল্ডিং নম্বর হলো: 4
মুদ্রার প্রতীক হলো: ৳

    🤔 char সম্পর্কে একটি গোপন তথ্য: একটি char আসলে একটি ইন্টিজার! এটি অক্ষরের জন্য নির্ধারিত ASCII কোড সংরক্ষণ করে। ASCII হলো একটি স্ট্যান্ডার্ড যা প্রতিটি অক্ষরের জন্য একটি অনন্য সংখ্যা নির্ধারণ করে। আপনি %d দিয়ে প্রিন্ট করে এটি প্রমাণ করতে পারেন।

    char amarOkkhor = 'A';

printf("অক্ষরটি হলো: %c\n", amarOkkhor); // অক্ষরটি প্রিন্ট করে
printf("এর আসকি (ASCII) মান হলো: %d\n", amarOkkhor); // সংখ্যাটি প্রিন্ট করে

    আউটপুট:

    অক্ষরটি হলো: A
এর আসকি (ASCII) মান হলো: 65

    ## Summary¶

    এখানে বেসিক ডেটা টাইপগুলো দ্রুত পর্যালোচনার জন্য একটি সারণী দেওয়া হলো।

    ডেটা টাইপ কী সংরক্ষণ করে মেমরি সাইজ ফরম্যাট স্পেসিফায়ার প্রাথমিক মান (উদাহরণ) আমরা যে মান দিতে পারি (উদাহরণ)
    int পূর্ণসংখ্যা 4 বাইট %d বা %i int score = 0; score = 100;
    float দশমিক সংখ্যা 4 বাইট %f float temp = 37.5; temp = 38.0;
    double উচ্চ-নির্ভুল দশমিক 8 বাইট %lf double daam = 99.0; daam = 99.999;
    char একটিমাত্র অক্ষর 1 বাইট %c char prothomOkkhor = 'J'; prothomOkkhor = 'S';

    ## ফ্লোচার্ট: সঠিক ডেটা টাইপ কীভাবে বেছে নেবেন¶

    কোন ডেটা টাইপ ব্যবহার করবেন তা ভাবার জন্য এখানে একটি ফ্লোচার্ট দেওয়া হলো। ১৯৭০-এর দশকে C তৈরির সময় থেকে এই সিদ্ধান্ত গ্রহণের প্রক্রিয়াটি একই রয়েছে!

    ## 🚨 সবচেয়ে গুরুত্বপূর্ণ নিয়ম 🚨¶

    সবসময় printf() ফাংশনে ডেটা টাইপের সাথে তার সঠিক ফরম্যাট স্পেসিফায়ার মেলান!

    ভুল স্পেসিফায়ার ব্যবহার করলে ভুলভাল আউটপুট, অদ্ভুত আচরণ বা এমনকি প্রোগ্রাম ক্র্যাশও করতে পারে।

    পরিস্থিতি কোড ফলাফল অবস্থা
    সঠিক int num = 10; printf("%d", num); 10 ✅ একদম ঠিক!
    ভুল int num = 10; printf("%f", num); 0.000000 (বা আবর্জনা মান) ❌ ভুল!
    ভুল float price = 9.99; printf("%d", price); 1717986918 (বা আবর্জনা মান) ❌ ভুল!
    ভুল char grade = 'A'; printf("%d", grade); 65 (ASCII মান) 🤔 বোঝা গেলেও, আপনি এটি চাননি।

    কম্পিউটার একটি ডেটা টাইপের বিট এবং বাইটকে অন্য একটি ডেটা টাইপ হিসাবে ব্যাখ্যা করার চেষ্টা করে, এবং ফলাফল প্রায় কখনই আপনার কাঙ্ক্ষিত হয় না। সুতরাং, আপনার % স্পেসিফায়ারগুলো সর্বদা দুবার পরীক্ষা করে নিন!

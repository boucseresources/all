    🧠 006. Variable Declaration vs Definition in C¶

    আমরা এখানে বুঝবো দুইটা জিনিস:

    1. Declaration (ঘোষণা) 📣
    2. Definition (সংজ্ঞা) 🧱

    🔎 সহজ ভাষায় পার্থক্য¶

    | 📌 ধরো আপনি কাউকে বললা:

    “ভাই, আমি একটা জায়গা রাখতেছি, সামনে গিয়ে ওখানে কিছু রাখবো।”
    এটা হলো Declaration

    | 📌 আর যখন আপনি বললা:

    “ভাই, এই জায়গায় আমি এখনই এই জিনিসটা রাখতেছি।”
    এটা হলো Definition

    🛠️ In C Programming Terms¶

    ✅ Declaration মানে:¶

    শুধু variable-টা আছে বলে জানানো, কিন্তু কোন value দেয়া হয় না।

    extern int age;  // Just saying: age নামে একটা variable আছে
    • এখানে extern keyword use করা হইছে কারণ আপনি শুধু বলতেছো যে variable টা exists, value দাওনি।
    • এটা useful যখন variable অন্য file-এ define করা হয় (multi-file projects).

    ✅ Definition মানে:¶

    Variable-টা declare করা এবং একই সাথে memory allocate করা হয়।
    Value না দিলেও, memory reserve হয়ে যায়।

    int age;         // Declaration + Definition
int roll = 101;  // Declaration + Definition + Initialization

    এখানে memory allocate হয়ে গেছে, আর roll এর ক্ষেত্রে value ও set করা হয়েছে।

    ⚙️ Table: Declaration vs Definition¶

    Feature Declaration Definition
    Purpose বলে দেয় যে variable আছে variable বানায় এবং memory রিজার্ভ করে
    Memory Allocation ❌ না ✅ হ্যাঁ
    Example extern int age; int age; বা int age = 25;
    Initialization ❌ না ✅ সম্ভব (চাইলেই value দিতে পারি)

    ⚠️ Warning! Variable Declare করা মানেই memory পাওয়া না 😬¶

    extern int number;

    ↑ শুধু বললাম যে number নামে কিছু একটা আছে। কিন্তু এটা এখনো বানানো হয়নি ❌
    অন্য কোন জায়গায় এটার definition থাকা লাগবে:

    int number = 5;

    🧪 Example: Declaration vs Definition (2 files)¶

    📁 main.c¶

    #include <stdio.h>

extern int age; // Declaration only

int main() {
    printf("Age: %d\n", age);  // Use external variable
    return 0;
}

    📁 data.c¶

    int age = 25; // Definition here

    ✅ Now compile both files together:

    gcc main.c data.c -o output
./output

    📤 Output:

    Age: 25

    🪄 Quick Recap (Bangla Summary)¶

    বিষয় ব্যাখ্যা
    Declaration Variable টা আছে এটা বলতেছি, কিন্তু value বা memory নাই
    Definition Variable declare করলাম এবং সাথে সাথে বানিয়েও ফেললাম
    extern কেবল declaration বোঝাতে ব্যবহার হয়
    Memory Declaration-এ নাই, Definition-এ আছে
    Real use case বড় বড় project বা multi-file project-এ Declaration দরকার

    🧑‍🏫 Practical Tip:¶

    আপনি যদি এখন শুধু এক ফাইলে কাজ করো, তাহলে Declaration নিয়ে মাথা ঘামানোর দরকার নাই — সবই Definition দিয়ে শুরু করো:

    int age = 18; // This is enough for now!
